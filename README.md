# mephi-linux-security-hw1
GNU/Linux Security - Homework 1
Уникальный номер: M265226
Операционная система: Ubuntu 24.04 LTS (GitHub Codespaces)
Раздел 1. Создание пользователя
Создан пользователь user1 с UID 1234 и основной группой students.
Настроена обязательная смена пароля через 90 дней.
Результаты проверки представлены в account-check.out.
Раздел 2. Мониторинг файлов и процессов
Мониторинг файлов: с помощью команды find выполнен поиск файлов с установленным битом Set-UID.
Мониторинг процессов: обнаружены процессы sudo, имеющие реальный UID 1000 и эффективный UID 0.
Артефакты:
suid-files.out
privileged-processes.out
Раздел 3. Механизм Set-UID
Выбрана утилита stat.
Создана её копия stat-suid с владельцем root и установленным битом Set-UID
При обращении к защищённому файлу обычной утилитой получен отказ в доступе
При использовании SUID-копии операция выполнена успешно
Вывод: Set-UID позволяет программе выполнять операции с эффективными правами владельца исполняемого файла
Раздел 4. Механизм Linux Capabilities
Выбрана утилита chown.
Её учебной копии назначена привилегия CAP_CHOWN.
Обычная команда не смогла изменить владельца файла на root.
Копия с назначенной привилегией успешно выполнила операцию.
Вывод: Linux Capabilities позволяют предоставлять программам отдельные полномочия без полного набора привилегий root.
Артефакты:
stat.out
getcap.out
Раздел 5. Механизм sudo
Создано правило sudoers, разрешающее пользователю user1 запускать /usr/bin/date с правами root.
Работоспособность разрешения подтверждена
Проверено наличие привилегии CAP_SYS_TIME у процесса root.
Фактическое изменение системного времени не проводилось из-за особенностей контейнерной среды
Артефакт: sudo-rule.out.
